Jarvis for Mac

A small menu-bar app that listens, remembers and acts, so you don't have to hold everything in your head.

Status: v1 is being built in the open. Items marked Planned are decided but not final. The code is open source (MIT) at github.com/yashMangal19/jarvis: fork it.

The idea

A clone for the part of you that forgets.

It listens.It remembers.It acts.

And it always asks before it acts on your behalf.

How it works

Five steps. Your audio never leaves your Mac.

  1. 01

    Listen

    Records you, your calls and, if you want, the room.

  2. 02

    Transcribe

    Turns speech into text on your Mac, then deletes the audio.

  3. 03

    Write notes

    Every hour, a short note of what was said.

  4. 04

    Remember

    Notes roll up into days and weeks, and you can search all of them.

  5. 05

    Act

    Say "Jarvis, …". It reads back its plan and acts after your yes.

Features

What it does.

Any Mac works everywhere. macOS 27 gets Apple's newest frameworks automatically.

Any Mac

Always listening, when you want it

Start and stop from the menu bar. The icon is red while recording.

How it's built

AVAudioEngine records the active mic in 30-second chunks.

A chunk that stays below a loudness threshold is silence. It is dropped and adds no transcript line.

Any Mac

Whole meetings, not just you

Online calls: the call audio is recorded too.

In person: turn on Meeting mode to record the room.

Lines are labelled Me or Others.

How it's built

We tested it. AirPods Pro caught the wearer clearly but heard a nearby podcast as "[INAUDIBLE]". The MacBook mic transcribed the same podcast almost word for word.

So the AirPods record you, ScreenCaptureKit records call audio (audio only, which needs the Screen Recording permission), and Meeting mode adds the built-in mic for the room.

Jarvis asks for Screen Recording once, on first launch. If you say no, it works with your mic only, and the menu shows "Call audio off — Allow Screen Recording…" in case you change your mind.

Each source is its own stream, and the source decides the label.

Known limit: the two mics hear each other's sounds. Your words reach the MacBook mic, and a phone or speaker nearby can reach the AirPods. So in Meeting mode a sentence can be stored twice, once per mic, and only one copy has the right label; notes may repeat it. Telling which mic really heard it is planned after 0.1.0.

Any MacmacOS 26+

Private transcription

Speech becomes text on your Mac. Audio is never uploaded or kept.

Hindi and Hinglish work too.

How it's built

whisper.cpp with a multilingual model that detects the language.

On macOS 26 and later, Apple's SpeechAnalyzer is used for the languages it supports, so there's nothing to download.

Settings → Engines shows which engine is in use.

On first run, Jarvis downloads the whisper model in the background and starts transcribing the moment the download finishes, with no restart.

Any MacmacOS 26+

Hourly notes

Each hour with speech becomes a short Markdown note: topics, decisions, to-dos, people.

Turn on Demo mode to get a note every 2 minutes.

How it's built

The first available writer is used: Claude Code (claude -p), then Apple FoundationModels on-device, then a local Ollama model (optional, about 2 GB).

With Claude Code, the hour's transcript text is sent to Anthropic to write the note. Apple's model and Ollama run entirely on your Mac.

With none available, the menu says "Notes off — install Claude Code or Ollama", and transcripts and search keep working.

Edit prompts/hourly.md to change how notes read.

Any Mac

Memory that stays small

Hourly notes become a daily note. Daily notes become a weekly note.

How it's built

Plain Markdown in notes/hourly, daily and weekly, under Jarvis’s data folder. Open notes in the menu shows them in Finder.

Raw transcripts are deleted after 7 days. Notes stay.

Any MacmacOS 14+

Ask your memory

"What did we decide about the launch on Tuesday?"

Jarvis answers and names the notes it used.

How it's built

Every note is turned into a vector and searched by similarity. Jarvis picks the best embedder this Mac has:

  • Core AI (macOS 27), a stronger embedding model. Planned The slot is ready, but no model ships yet.
  • NLContextualEmbedding (macOS 14+), built in with no download. This is the default today.
  • NLEmbedding on older Macs.

The index remembers which embedder built it, so switching engines rebuilds the index instead of mixing results.

Any Mac

Voice commands

"Jarvis, tell the team I'm 10 minutes late."

It uses the tools you've connected to Claude Code: chat, calendar, GitHub and more.

How it's built

Three ways to start:

  • say "Jarvis, …"
  • hold ⌥Space, speak, then release
  • squeeze an AirPods stem (experimental, off by default: turn it on in Settings). Side effects while it's on: the AirPods stay attached to your Mac, the Mac may not idle-sleep, Music loses Now Playing, and taking an AirPod out or pressing play/pause can start a command.

Claude drafts the action, Jarvis speaks the draft, and you say yes.

Say it in one breath. There's no need to wait after "Jarvis": it keeps the last few seconds in memory (never on disk), so it catches what you say right after the wake word. A soft chime tells you it heard you.

Any Mac

Control it by voice

"Jarvis, pause." "Jarvis, resume."

Also: meeting mode on/off, demo mode on/off, forget the last hour, and "what did …?" If Jarvis half-hears one of these, it asks "Did you mean …?" and acts only on yes.

How it's built

Jarvis handles these itself, without Claude, so they're instant and confirmed with a tick sound.

"Forget the last hour" can't be undone, so Jarvis reads it back and waits for your yes.

Controls always win. If you say "Jarvis, pause" while Jarvis is waiting for your yes on another command, it says "Cancelled.", drops that command and pauses.

If your AirPods disconnect, "Jarvis, resume" keeps going on the MacBook mic. Jarvis says "Listening through the MacBook mic" and switches back when the AirPods return.

Any Mac

It asks before it acts

Nothing is sent, booked or changed until you've heard the plan and said yes.

How it's built

Every command runs in two phases: a read-only draft, then execution.

The read-back says exactly what will happen, to whom, and with what content.

Yes runs it. No, or 15 seconds of silence, drops it. What you say after that is treated as a new request.

Anything else is treated as a correction ("no, send it to Prashant instead"). Jarvis redrafts and reads the new plan back. After 3 corrections without a yes, it gives up and tells you.

Later: Jarvis learns how you talk, so it needs fewer words and fewer confirmations.

Only the tools you tick in Settings can run. Shell commands and file edits are off by default.

Claude runs in a locked-down mode: your own Claude settings aren't loaded, anything not allowed is refused instead of asking, and it works in a scratch folder.

Any Mac

Away from your Mac

Record on your phone. Jarvis adds the recording to your memory when the Mac wakes.

How it's built

iPhone: Voice Memos sync over iCloud and are imported automatically. The first time, Jarvis asks for Full Disk Access, with a button that opens the right Settings page. Only memos recorded after that are imported. To add older ones, drop them in Jarvis’s inbox folder.

A recording is removed from the inbox only after it has been transcribed. If transcription fails, it stays and is tried again.

Android: save recordings into a synced folder that points at Jarvis’s inbox folder (~/Library/Application Support/Jarvis/inbox).

Imported recordings are labelled Me.

If your AirPods disconnect, Jarvis pauses and marks the gap in that hour's note. Say "Jarvis, resume" to continue on the MacBook mic.

Privacy

You can always tell. You stay in control.

  • The icon is red while recording.
  • Pause with a click or "Jarvis, pause". Nothing is recorded, but "Jarvis, …" still works: ask a question, give a command or say "resume". The icon goes grey with a dot.
  • Stop from the menu turns everything off, wake word included. The icon goes plain grey. Holding ⌥Space still gives a command: the mic is on only while you hold the key, and nothing is saved.
  • It stops on its own when your screen locks and during quiet hours you set, checked from the moment it launches. Quiet hours stop it even while paused, and when they end your pause is still in place. Want it on anyway? Click Start listening: it stays on until that night's quiet hours end.
  • Pausing cuts the recording at that exact moment. Nothing after a pause is saved, and nothing before it is lost.
  • Audio is never stored and never uploaded. Audio stays in memory. The one exception: if the whisper server is down, the fallback writes a temporary file and deletes it once transcribed.
  • What leaves your Mac: only text, and only to the AI you use. If Claude Code writes your notes, each hour's transcript text goes to Anthropic. A voice command's words go to Claude so it can draft the plan, before you say yes. Only the action itself waits for your yes.
  • Want nothing to leave? Use Apple's on-device model (macOS 26+) or Ollama for notes, and skip voice commands.
  • Forget last hour deletes that hour's transcript, voice-command records, notes and search entries, including anything still being written. It deletes exactly the hour it showed you, even if you take a while to confirm.
  • If the microphone permission is off, the menu says so, with a button to fix it. A red icon always means it can really hear.

Tell people when you're recording them. Consent and local laws apply to you.

Requirements

What you need.

MacRuns on macOS 13 or later. Installing builds it from source, which needs macOS 14.5+ (Swift 6). macOS 27 on Apple Silicon for the newest features.
ToolsHomebrew and the Xcode Command Line Tools 16 or later (Swift 6). Xcode 27 for the newest features.
AIClaude Code with a Claude plan. Without it, Apple's on-device model (macOS 26+) or Ollama writes notes.
MicBuilt-in mic or any earbuds. AirPods are best for your own voice.
Install

One command. After publish

brew install yashMangal19/tap/jarvis
jarvis   # first run: copies the speech models and opens Jarvis

Or from source:

git clone https://github.com/yashMangal19/jarvis
cd jarvis && ./install.sh

  3. 03

    Start listening

Your data

Plain files you own.

~/Library/Application Support/Jarvis/
├── inbox/          phone recordings to import
├── transcripts/    deleted after 7 days
├── logs/           your voice commands, deleted after 7 days
├── notes/
│   ├── hourly/
│   ├── daily/
│   └── weekly/
├── index/          for search
└── prompts/        edit to change your notes
Build on top

Swap any step.

Each step is a small Swift protocol. Replace one without touching the rest. Planned API

protocol Transcriber   { func transcribe(_ chunk: AudioChunk) async throws -> String }
protocol NoteWriter    { func note(from transcript: String, prompt: String) async throws -> String }
protocol Embedder      { func embed(_ text: String) throws -> [Float] }
protocol CommandRunner {
  func draft(_ command: String) async throws -> String   // never acts
  func execute(_ draft: String) async throws -> String   // only after "yes"
}

Decisions

What we've decided, and why.

Every decision is recorded in DECISIONS.md in the repo. Each new one is checked against it first. These are the ones you'll notice. Updated 18 Oct 2026.

Controls winA control said while Jarvis waits for your yes cancels that command, then runs.
Honest privacyAudio stays on your Mac. Transcript text goes to Claude only if Claude writes your notes or drafts your commands.
Stem squeezeOpt-in. Hearing a squeeze means playing silence while Jarvis listens, which can keep the AirPods on your Mac, stop it sleeping and take Now Playing from Music. Taking an AirPod out, a Bluetooth drop or the play/pause key can also start a command.
Hold to talk⌥Space works even when Jarvis is stopped. The mic is on only while you hold the key.
Clean cutsPausing ends the current recording block on the spot, so no speech is lost either side.
No restartTranscription starts as soon as the speech model has downloaded.
AirPods goneJarvis pauses. "Jarvis, resume" continues on the MacBook mic and tells you so.
Quiet hoursNothing automatic overrides them, wake word included. You can, with one click, until they end.
Asked onceScreen Recording (call audio) is asked for once. A "no" is remembered, and you can turn it on later from the menu.
SearchCore AI (planned) → NLContextualEmbedding → NLEmbedding, picked per Mac.
Voice MemosOnly new memos are imported. Older ones go through the inbox.
No audio on diskAudio is processed in memory. A brief temp file is used only as a fallback.
Claude locked downYour own settings aren't loaded. Only the tools you ticked can run. It runs in a scratch folder.
Own speechJarvis's voice is removed from call audio. The mic may still catch a read-back.
SwappableEvery engine is a plug-in point. With none installed, transcripts and search keep working.
